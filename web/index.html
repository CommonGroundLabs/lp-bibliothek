    LP Bibliothek

    Deine Platten, dein Katalog.

    Verbinde deinen Discogs-Account. Die Sammlung wird einmalig lokal gespeichert – danach läuft die Bibliothek offline, ohne Backend, ohne Konto bei mir.

    1. 1 Benutzername
    2. 2 Token einfügen
    3. 3 Sammlung laden

    Der Token geht ausschließlich an diesen Server auf deinem Rechner und landet in .env (von .gitignore ausgeschlossen). Er taucht in keiner Antwort und keinem Log auf.

    Diese Seite läuft ohne lokalen Server, deshalb kann hier kein Account verbunden werden. Starte die Einrichtung auf deinem Rechner:

    python3 setup.py

    Danach im Browser http://127.0.0.1:8765 öffnen. Fürs Hosten der Seite nach dem Sync genügt der Ordner web/.

    Sammlung wird geladen …

    Bei großen Sammlungen dauert das 20–60 Minuten (Discogs erlaubt ~60 Anfragen pro Minute). Der Fortschritt läuft hier live mit.
